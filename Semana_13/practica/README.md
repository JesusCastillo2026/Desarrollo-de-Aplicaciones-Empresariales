# Práctica de cafetería — Semana 13

Este scaffold separa configuración de Django y apps de negocio, y crea el esqueleto React requerido. Los modelos y endpoints del catálogo, inventario, carrito y checkout se desarrollan en semanas posteriores.

- Backend Django: `backend/core`, `backend/catalogo`, `backend/pedidos`.
- Frontend: `frontend/src/components`, `frontend/src/pages`, `frontend/src/api.js`.
- Mapa de rutas y respuestas de los ejercicios: [README del laboratorio](../README.md).

Ejecuta `python manage.py check` desde `backend`; para frontend, `npm run lint` y `npm run build` desde `frontend`.
